# Word swaps

Words that AI-written text overuses, with plain replacements. If a word carries no fact, delete it instead of replacing it. Adapted from SimpleEnglish (see `../LICENSE`).

| Overused | Write instead |
|---|---|
| leverage, utilize, harness | use |
| in order to | to |
| prior to | before |
| ensure | check, or state the requirement with "must": "The file must exist." |
| it is worth noting that, it is important to note | (delete, then state the fact) |
| simply, just, easily, seamless, seamlessly, effortlessly | (delete) |
| robust, powerful, comprehensive, performant | (delete, or give the measurable property) |
| crucial, crucially, pivotal, paramount, vital | (delete, then state the fact) |
| functionality | function, feature |
| enables you to, allows you to | you can |
| is designed to, aims to | (delete, then say what it does) |
| facilitate | help, make possible |
| dive into, delve into | read, examine |
| when it comes to | for |
| in the event that | if |
| due to the fact that | because |
| as needed, as necessary | (state the condition) |
| and/or | Pick one, or write "X, Y, or both" |
| e.g., i.e., etc. | for example, that is, (name the items) |
| gracefully handles | (say what it does: "retries three times, then stops") |
| out of the box | by default |
| under the hood | internally |
| blazingly fast | fast (give the number) |
| streamline | simplify, speed up |
| plethora, myriad | many |
| addresses the issue, tackles | fixes |
| tapestry, testament, synergy, interplay | (delete) |
| intricate | complex |
| nuanced, multifaceted | (delete, or name the parts) |
| realm, landscape (as a metaphor) | area |
| groundbreaking, cutting-edge, state-of-the-art, innovative | new (or delete) |
| transformative, game-changer, revolutionize | (delete, then say what changes) |
| showcase, underscore, emphasize | show |
| foster, empower, bolster | help, support, let |
| enhance | improve |
| elevate | increase |
| furthermore, moreover | also |
| however | but |
| therefore | so, as a result |
| since (meaning because) | because |
| perform | do, run |
| in conclusion, in summary, at the end of the day | (delete) |

| meticulous, meticulously | careful, carefully |
| holistic | full |
| paradigm | model |
| navigate (as a metaphor) | go to, use |
| boasts | has |
| that being said, notwithstanding | but |
| genuinely, actually, really, honestly | (delete) |
